SOCIAL IMPACT CLUB WEBSITE
===========================

Files:
- index.html
- style.css
- script.js
- social-impact.jpg

How to run:
1. Extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in Chrome/Edge.
4. For VS Code, install Live Server if desired and open index.html with Live Server.
