# Stage & Spotlight - IDEAL Performing Arts Club

## Files
- index.html
- style.css
- script.js
- stage-spotlight.jpg

## Setup
1. Put your poster/image in this folder.
2. Rename the image to `stage-spotlight.jpg`.
3. Open `index.html` in Chrome/Edge.

## Features
- Responsive design
- Stage & Spotlight theme
- Activities section
- Events section
- Join Club form
- Registration success popup
- Search
- Mobile navigation
- Gallery
- Footer
